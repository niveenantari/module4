Scoring rule: error ≤ 10% earns 100 points for that parameter. Beyond 10%, 2 points are subtracted for each additional percentage point (minimum 0). The round score averages the two parameter scores.

Useful Methods

First-order step: steady value = K for a unit step; at t = τ, the output reaches 63.2% of that value.

First-order sine: use the known input frequency, the output/input amplitude ratio, and the phase lag to estimate τ and K.

Second-order underdamped step: overshoot identifies ζ; peak time helps identify ωn.
