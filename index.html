Scoring rule: error ≤ 10% earns 100 points for that parameter. Beyond 10%, 2 points are subtracted for each additional percentage point (minimum 0). The round score averages the estimated parameter scores; for critical damping, ζ = 1 is known, so only ωₙ is scored.

Useful Methods

First-order step: steady value = K for a unit step; at t = τ, the output reaches 63.2% of that value.

First-order sine: use the known input frequency, the output/input amplitude ratio, and the phase lag to estimate τ and K.

Second-order underdamped step: overshoot identifies ζ; peak time helps identify ωn.

Second-order critically damped step: ζ = 1; 26.4% of final output occurs at t = 1/ωn.

Second-order overdamped step: Read the times when the output reaches 50% and 90% of its final value (t50, t90). Calculate R = t90 / t50, then compare it with these reference values for a normalized sensor (ωn = 1 rad/s):
